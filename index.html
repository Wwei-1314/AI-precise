CSV 导入格式
推荐表头：章节,题型,题干,选项A,选项B,选项C,选项D,答案,解析
（题型、解析可省略；表头中英文均可自动识别）
题型取值：闪卡 / 单选 / 多选 / 配伍
闪卡：题干=正面，答案=背面（适合逐句背诵）
单选：答案为 A / B / C / D 或选项文本
多选：答案为 ABC / A,C / 选项1;选项2
配伍：同一组题共享相同的选项列，答案逐行指定；可用"组号"列显式分组
选项可用"选项A~H"多列，或单列"选项"用分号(;)分隔
文件编码支持 UTF-8 / GBK，自动识别
